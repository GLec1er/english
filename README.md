# English Grammar in Use — тренажёр

Сайт-тренажёр по темам книги Raymond Murphy *English Grammar in Use* (intermediate, 145 юнитов, нумерация 4-го и 5-го изданий).
Работает на GitHub Pages, без сервера и регистрации: прогресс хранится в браузере.

## Что внутри

Для каждого из 145 юнитов есть краткое правило на русском и задания:

| Навык | Задания |
|---|---|
| Грамматика | ☑️ выбор ответа · ✏️ впиши форму · 🧩 порядок слов · 🔍 найди ошибку |
| Письмо | 🔁 перефразируй по заданию · 📝 свободное письмо (с примером и самопроверкой) |
| Аудирование | 👂 услышь и впиши пропуск · 🎧 диктант (с подсветкой ошибок по словам) |
| Произношение | 🎤 произнеси фразу — браузер распознаёт речь и показывает, какие слова не получились |

Ещё на сайте:

- **Микс** — случайные задания из выбранных разделов или только из юнитов, отмеченных «выполнен в книге».
- **Ошибки** — все задания, где вы ошиблись, собираются для повторения. Задание уходит из списка после правильного ответа.
- **Звуки** — окончания -ed (/t/ /d/ /ɪd/) и -s (/s/ /z/ /ɪz/), сокращения и слабые формы на слух, трудные слова, скороговорки на грамматику.
- **Настройки** — британский или американский акцент, выбор голоса, скорость речи, сохранение прогресса в файл и перенос на другое устройство.
- **Календарь** — один юнит в день с понедельника по пятницу; в субботу и воскресенье — отдельное повторение юнитов недели. Показывает активные дни, подходы, задания и долю верных ответов.

Озвучка и распознавание речи работают через встроенные возможности браузера (Web Speech API).
Лучше всего всё работает в **Chrome** (на компьютере и на Android). В Safari и Firefox распознавание может быть недоступно — тогда в заданиях на произношение можно записать свой голос и сравнить с образцом.

## Как включить GitHub Pages

1. Слейте эту ветку в `main` (или выберите эту ветку на шаге 3).
2. В репозитории откройте **Settings → Pages**.
3. В блоке **Build and deployment** выберите *Source: Deploy from a branch*, ветку `main` и папку `/ (root)`, нажмите **Save**.
4. Через минуту сайт будет доступен по адресу `https://<ваш-логин>.github.io/english/`.

Локально можно просто открыть `index.html` в браузере.

## Рабочая тетрадь

Главная показывает оглавление, последний открытый юнит и прогресс. Включите фильтр «Пройдено в книге», чтобы видеть только отмеченные юниты. Отметка ставится на странице юнита и используется в смешанной практике.

В настройках доступны светлая, тёмная и системная темы. Выбор сохраняется в этом браузере вместе с остальными настройками. Старые файлы прогресса совместимы; юнит с завершённой попыткой учитывается даже при результате 0%.

Для проверки на локальном сервере без установки зависимостей:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Откройте `http://localhost:4173/`. Клавиши 1–9 выбирают варианты ответа; Enter проверяет введённый ответ. Все основные действия доступны с клавиатуры.

В режиме «Произнеси» процент отражает совпадение распознанных слов с образцом. Это вспомогательная практика речи, а не измерение качества акцента.

## Недельный план

На главной выберите юнит на сегодня. Будний план выполнен после основного набора: впиши форму, перефразируй, свободное письмо, диктант. Можно переключиться на все доступные упражнения юнита. Каждый пункт требует полного подхода; процент правильных ответов не блокирует закрытие дня. Обычный микс и повтор ошибок попадают в статистику, но не заменяют план.

В выходные кнопка «Начать повторение» собирает до 15 разных примеров из юнитов, к которым завершены подходы в будни этой недели. Если юнитов больше 15, набор увеличивается, чтобы охватить каждый. После завершения набор закрывает план только соответствующего выходного; в воскресенье нужен новый подход. Повтор ошибок после набора записывается отдельно. При отсутствии юнитов показывается пустое состояние.

Календарь начинается с понедельника и использует местные даты устройства. Занятие записывается в день завершения; незавершённые подходы не учитываются. Процент верных ответов считается по числу полностью правильных ответов, с учётом ручного подтверждения ответа. Свободное письмо учитывается без оценки правильности.

История начинается с обновления, прежние лучшие результаты сохраняются. Журнал `egiu:activity` и выбор юнита `egiu:dailyPlan` включены в общий экспорт/импорт прогресса. Для проверки календарной логики без зависимостей: `node --test tests/*.test.cjs`.

## The Study Club

За впервые завершённый режим в день начисляется 10 XP, за закрытие буднего набора — ещё 20 XP. Каждый выходной с недельным повторением даёт 25 XP; полная неделя — 50 XP и печать в коллекцию. Повтор режима, в том числе на другом юните, сохраняется как подход без повторных XP. Уровень практики повышается каждые 200 XP и не оценивает владение языком.

Главная и календарь показывают XP и серию закрытых дней. Сегодняшний незавершённый день не обнуляет вчерашнюю серию; выходной без материала для повторения её не разрывает. После подхода появляется следующий пункт дневного набора; при закрытии дня — короткая печать с учётом настройки уменьшения движения.

Выбранный юнит и набор дня хранятся в `egiu:club`, упражнения записывают режим в журнал. Нельзя объединить упражнения разных юнитов для одной цели. До закрытия можно сменить юнит; после закрытия цель сохраняется, а нагрузку можно изменить для следующих дней. Старые отметки календаря до запуска системы наград остаются по прежнему правилу; старые подходы без режима не выдают вымышленные отметки упражнений. Награды вычисляются из истории, экспорт включает цели и даты начала.

## Как добавить свои задания

Задания лежат в `js/data/*.js`, по одному файлу на раздел книги. Формат описан в `js/registry.js`:

```js
EGIU.unit(1, 'Present continuous (I am doing)', {
  tip: 'Краткое правило',
  g: ["Please be quiet. I [am trying|try|tried](try) to work."],   // первый вариант — правильный
  e: ["Look! It rains. => Look! It's raining."],                  // ошибка => исправление
  t: ["Ann is in the shower. (have a shower) => She's having a shower."],
  w: ['Задание для письма', 'Пример ответа'],
});
```

Из одного предложения в `g` автоматически строятся шесть заданий: выбор ответа, впиши форму, порядок слов, услышь и впиши, диктант и произношение.
Сокращения (`I'm` = `I am`, `don't` = `do not`, `'s` = `is`/`has`) при проверке считаются одинаковыми.

Упражнения составлены заново по темам книги, тексты из книги не копировались.
