# English Grammar in Use — тренажёр

Сайт-тренажёр по темам книги Raymond Murphy *English Grammar in Use* (intermediate, 145 юнитов, нумерация 4-го и 5-го изданий).
Работает на GitHub Pages, без сервера и регистрации: прогресс хранится в браузере.

## Что внутри

Для каждого из 145 юнитов есть краткое правило на русском и задания:

| Навык | Задания |
|---|---|
| Грамматика | ☑️ выбор ответа · ✏️ впиши форму · 🧩 порядок слов · 🔍 найди ошибку |
| Письмо | 🔁 перефразируй по заданию · 📝 свободное письмо (с примером и самопроверкой) |
| Аудирование | 👂 услышь и впиши пропуск · 🎧 диктант (с подсветкой ошибок по словам) |
| Произношение | 🎤 произнеси фразу — браузер распознаёт речь и показывает, какие слова не получились |

Ещё на сайте:

- **Микс** — случайные задания из выбранных разделов, только по юнитам с подтверждённым прохождением в книге.
- **Ошибки** — все задания, где вы ошиблись, собираются для повторения. Задание уходит из списка после правильного ответа.
- **Звуки** — окончания -ed (/t/ /d/ /ɪd/) и -s (/s/ /z/ /ɪz/), сокращения и слабые формы на слух, трудные слова, скороговорки на грамматику.
- **Настройки** — британский или американский акцент, выбор голоса, скорость речи, сохранение прогресса в файл и перенос на другое устройство.
- **Календарь** — один юнит в день с понедельника по пятницу; в субботу и воскресенье — отдельное повторение юнитов недели. Показывает активные дни, подходы, задания и долю верных ответов.

Озвучка и распознавание речи работают через встроенные возможности браузера (Web Speech API).
Лучше всего всё работает в **Chrome** (на компьютере и на Android). В Safari и Firefox распознавание может быть недоступно — тогда в заданиях на произношение можно записать свой голос и сравнить с образцом.

## Как включить GitHub Pages

1. Слейте эту ветку в `main` (или выберите эту ветку на шаге 3).
2. В репозитории откройте **Settings → Pages**.
3. В блоке **Build and deployment** выберите *Source: Deploy from a branch*, ветку `main` и папку `/ (root)`, нажмите **Save**.
4. Через минуту сайт будет доступен по адресу `https://<ваш-логин>.github.io/english/`.

Локально можно просто открыть `index.html` в браузере.

## Рабочая тетрадь

Главная показывает оглавление, последний открытый юнит и прогресс. Включите фильтр «Пройдено в книге», чтобы видеть только отмеченные юниты. На странице юнита первый шаг выделен отдельной карточкой: подтвердите, что прошли правило и задания у Мёрфи. До этой отметки упражнения, экзамен и контекстная практика закрыты, включая прямые ссылки. Микс использует только подтверждённые юниты; недельное повторение, ошибки и интервальная практика также запрашивают недостающие отметки перед началом. Снятие отметки снова закрывает доступ к заданиям, сохраняя ответы, экзамены, закрытые дни и ранги.

В заголовке каждой темы, включая свёрнутую, показаны крупный счётчик закрытых юнитов, общее количество и остаток. Каждый сегмент полосы соответствует своему юниту по порядку: при начале с середины раздела заполнены именно закрытые позиции. Закрытые строки выделены зелёным, значком подтверждения и подписью «Юнит закрыт»; на странице урока есть отдельная печать с датой зачёта. Учитываются официально закрытые юниты после экзамена. Поиск и фильтр книги не уменьшают общее количество юнитов темы.

Цвет счётчика, рамки, фона и заполненных сегментов раздела меняется по мере закрытия юнитов: от красного при 0% через янтарный к зелёному при 100%. Для светлой и тёмной темы используются отдельные оттенки; точные числа сохраняются рядом с цветом.

В настройках доступны светлая, тёмная и системная темы. Выбор сохраняется в этом браузере вместе с остальными настройками. Старые файлы прогресса совместимы; режим с завершённой попыткой учитывается даже при результате 0%. Процент выполнения отделён от правильности ответов.

Для проверки на локальном сервере без установки зависимостей:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Откройте `http://localhost:4173/`. Клавиши 1–9 выбирают варианты ответа; Enter проверяет введённый ответ. Все основные действия доступны с клавиатуры.

В режиме «Произнеси» процент отражает совпадение распознанных слов с образцом. Это вспомогательная практика речи, а не измерение качества акцента.

## Разбор ответов

После проверки каждого задания появляются **перевод полного правильного предложения** и короткое объяснение конкретной формы: почему она подходит к ситуации и чем отличаются другие варианты. Разбор доступен при верном и неверном ответе, во всех режимах юнита, в миксе, недельном повторении и работе над ошибками. До проверки он скрыт. В свободном письме перевод и пояснение раскрываются вместе с образцом; собственный текст пользователя автоматически не переводится.

Все 145 юнитов содержат 2030 заметок к исходным примерам и образцам письма. Лаборатория звуков содержит ещё 152 перевода слов и фраз с пояснениями произношения. Один пример использует одну заметку во всех режимах, где он встречается. Содержание хранится в `js/notes-data.js`; строки имеют формат `[исходный английский, перевод, объяснение]`. Совпадение исходного текста проверяется, чтобы изменённое задание не получило чужой разбор. HTML в заметках не исполняется. Внешний API перевода не используется.

Для 21 примера дополнительно учтены корректные варианты: например, each/every, некоторые позиции наречий и turn off/out the lights. Они перечислены четвёртым элементом строки заметки и засчитываются в выборе ответа, вписывании формы и перефразировании. В Unit 36 также принимаются «Tom promised he would help you» и «If I had a lot of money, I would travel a lot». В первом задании адресат обещания не указан, во втором дополнительное a lot сохраняет нужную конструкцию. В порядке слов допустимы проверенные перестановки из того же набора слов. В аудировании проверяется именно озвученная форма: другая грамматически возможная форма не подменяет услышанный ответ. Разбор поясняет такую разницу. Существующие сохранённые результаты не пересчитываются.

Справочные материалы по смыслу [would](https://dictionary.cambridge.org/grammar/british-grammar/would), [wish](https://dictionary.cambridge.org/grammar/british-grammar/wish) и конструкциям с [suggest](https://dictionary.cambridge.org/grammar/british-grammar/suggest) и [местоимениям в косвенной речи](https://dictionary.cambridge.org/grammar/british-grammar/reported-speech-indirect-speech) — Cambridge English Grammar Today. Заметки к примерам написаны по-русски отдельно и не являются цитатами из справочника.

## Недельный план

На главной показан очередной юнит курса. Все упражнения юнита открывают **итоговый экзамен**. Его сдача (от 80%, минимум 11 из 13) закрывает текущий юнит и будний день. Каждый проверенный ответ сохраняется сразу: карточки показывают `3 / 8 · 38% выполнено`, а повторное открытие незавершённого режима продолжает оставшиеся задания. Последний ответ засчитывается до кнопки «Результат». Завершённые режимы можно повторять без удаления прежних отметок.

Нулевой результат не блокирует выполнение отдельного режима, но для закрытия дня нужно сдать экзамен. Лучший процент правильности показан отдельно. Обычный микс и повтор ошибок попадают в статистику, но не заменяют задания юнита.

Новые уроки открываются строго по порядку: все упражнения и экзамен предыдущего юнита → следующий юнит в следующий будний день. Новый раздел недоступен, пока не закрыты все юниты текущего раздела. Ручного выбора дневной цели нет; прежняя незакрытая цель на произвольный юнит исправляется на очередную. Проверка действует на странице урока, по прямым ссылкам на все упражнения, экзамен и контекст, а также при зачёте дня. В оглавлении видны текущий раздел и замки с номером юнита, который нужно закончить. Сохранённые частичные ответы, старые закрытые дни и ранги сохраняются.

Не более одного нового юнита в будний день; после закрытия дня и в выходные остаётся закрепление. Закрытые юниты доступны для повторения без увеличения счётчика. Исключение личного старта с середины: юниты **1–35 остаются открытыми для дополнительной практики** после отметки книги, пока основной маршрут идёт от 36-го до 145-го. Такая практика сохраняет ответы, но не подменяет дневную цель и не закрывает второй юнит. После 145-го ранние юниты предлагаются по порядку, начиная с первого незакрытого. Микс использует только доступные юниты после книги. Собственные сохранённые ошибки и недельное повторение доступны отдельно, чтобы прежние ошибки из теперь закрытого для новых уроков раздела можно было исправить.

### Ошибки недели перед новыми уроками

В выходные сначала открывается недельная работа над своими ошибками: сохранённый неверный ответ, правильный вариант, перевод и объяснение. Для каждого примера нужно прочитать разбор, правильно выполнить исходное задание и два дополнительных задания темы. Ошибки на слух получают диктант и пропуск на слух. Все шаги сохраняются отдельно, в том числе незаконченная работа.

Оглавление и календарь заранее предупреждают о сроке. С понедельника новые незакрытые юниты недоступны, пока остаются ошибки любой предыдущей недели. Прямые ссылки на упражнения, экзамен и контекст также проверяют допуск; смешанная практика на время долга использует только закрытые юниты. После завершения работы уроки открываются сразу. Неделя без ошибок не создаёт блокировку. Обычное повторение всей недели следует после её ошибок.

Недельный зачёт не заменяет повторения через 1, 3 и 7 дней и не удаляет исходную историю. При первом включении учитываются только ошибки текущей недели с известной датой; старые недатированные ошибки остаются в прежнем журнале. Прогресс работы экспортируется вместе с остальными данными. Два дополнительных контекста с новой лексикой построены из проверенных рецептов всех 145 тем; варианты экзаменов A/B не изменены. Автоматических запросов к API нет.

Для личного курса начальная тема — **36**, с 12 октября 2026. При первом запуске этого обновления юниты **1–35 отмечаются только в книге**; результаты приложения не выдумываются. После закрытия 36 следующий план предлагает 37; дополнительная практика ранних тем не сдвигает цель. Пропущенная часть первого начатого раздела остаётся исключением; следующие разделы проходятся целиком по порядку. Существующие данные сохраняются; новые профили применяют эту личную начальную настройку.

В выходные «Начать повторение» собирает до 15 разных примеров из тем, где в будни проверен хотя бы один ответ, сохранено письмо или засчитан готовый юнит. Каждый юнит представлен; если их больше 15, набор увеличивается. Суббота и воскресенье закрываются отдельными подходами. При отсутствии материала показывается пустое состояние.

Календарь использует местные даты устройства. Частичные ответы входят в статистику сразу. Итог режима не дублирует ответы; возобновление после выхода — отдельный подход. Правильность считается по полностью верным ответам с учётом ручного подтверждения. Свободное письмо учитывается без оценки правильности.

Журналы `egiu:exams`, `egiu:mistakes`, `egiu:steps`, `egiu:course`, `egiu:activity`, `egiu:dailyPlan` и `egiu:club` включены в общий экспорт/импорт. Старые полные попытки остаются выполненными, даже при 0%; старые календарные отметки до начала нового курса остаются по прежнему правилу. Проверка логики: `node --test tests/*.test.cjs`.

## Экзамен и закрепление ошибок

После всех режимов на странице юнита и в дневном плане появляется экзамен: 13 разных существующих примеров, семь форматов (выбор, форма, порядок слов, исправление, перефразирование, аудирование с пропуском, диктант). Если для порядка слов нет подходящих предложений, его заменяет вписывание формы. Один пример не повторяется в одной попытке. Это проверка знакомого материала, не отдельный новый банк.

Для сдачи нужно 11 из 13 полностью правильных ответов. Подсказка с вариантами, отметка правильности, перевод и объяснение скрыты до конца. В аудировании проверяется услышанная форма; грамматически допустимая замена не подменяет запись. Свободное письмо и произношение остаются упражнениями юнита; в экзамене используются только форматы с автоматической проверкой. Сравнение основано на предусмотренных вариантах и нормализации сокращений; произвольные новые формулировки не оцениваются языковой моделью.

Каждый экзаменационный ответ сохраняется сразу; выход и перезагрузка позволяют продолжить оставшиеся вопросы в том же порядке. Последний ответ сохраняет итог и закрывает текущий будний юнит при сдаче. Разбор всех вопросов, результат по форматам и лучшая оценка доступны после завершения. Пересдача не даёт дополнительных XP/рангов и не отменяет прежнюю сдачу. В выходной или на другой теме результат сохраняется как практика; официальный лимит — один юнит курса в будний день. Старые закрытые дни не пересматриваются.

Журнал ошибок хранит последнюю неверную формулировку, режим, число ошибок, степень закрепления и следующую дату. После новой ошибки первый срок — завтра. Верная проверка в срок переносит пример на 3 дня, следующая — на 7 дней; третья верная проверка переводит его в закреплённые. Новая ошибка сбрасывает степень, включая ранее закреплённые примеры. Ранний правильный ответ или несколько правильных ответов за день не ускоряют интервалы. Ручное подтверждение в обычной практике отменяет только ошибочную запись этого ответа.

Очередь на сегодня сортируется по сроку и повторяемости ошибок, до 20 за подход. Старые ссылки на ошибки мигрируют без удаления и доступны сегодня. Форматы пропусков меняются: ввод формы, порядок слов, диктант; варианты ответа в закреплении скрыты. Исправление/перефразирование сохраняют исходный тип. Перевод, объяснение и дата повторения показаны после проверки. Закреплённые примеры доступны в отдельном раскрываемом списке. Недельный повтор сначала включает просроченные ошибки из тем этой недели и сохраняет представление каждого юнита.

## The Study Club

За впервые завершённый режим в день — 10 XP, за закрытие буднего юнита — 20 XP. Каждый выходной с недельным повторением даёт 25 XP; полная неделя — 50 XP и печать. Повтор режима, в том числе на другом юните, сохраняется без повторных XP. Награды вычисляются из истории и не дублируются при перезагрузке.

Полностью закрытый сегодняшний день отмечается наградной страницей Study Club: печать, юнит, сданный экзамен, XP за сегодня, серия и текущий ранг. Она появляется после закрытия юнита, остаётся на главной и в календаре до следующего дня. В выходные нужно завершить недельное повторение и обязательную работу над ошибками; после последнего шага закрепления награда показывается сразу. Этот экран использует существующие журналы и не начисляет дополнительные награды.

**Ранг зависит от разных официально закрытых юнитов**, а не от XP или номера книги:

| Ранг | Юнитов |
|---|---:|
| Commoner · Простолюдин | 0 |
| Yeoman · Йомен | 1 |
| Esquire · Эсквайр | 10 |
| Knight · Рыцарь | 25 |
| Baron · Барон | 45 |
| Viscount · Виконт | 65 |
| Earl · Граф | 85 |
| Marquess · Маркиз | 105 |
| Duke · Герцог | 125 |
| King · Король | 145 |

Это игровая лестница по мотивам английских сословий и титулов. Порядок пяти титулов сверён с [UK Parliament](https://publications.parliament.uk/pa/ld199798/ldbrief/ldguide3.htm); пороги выбраны для курса и не воспроизводят историческую социальную систему. Экран «Лестница рангов» показывает текущий ранг и следующий порог.

Серия закрытых дней сохраняется, пока сегодняшний день ещё впереди; прошедший пропуск её прерывает, XP остаётся. Выходной без материала для повторения не разрывает серию. Печати первого дня, обоих выходных и полных недель сохраняются. Анимация печати учитывает уменьшение движения.

## Как добавить свои задания

Задания лежат в `js/data/*.js`, по одному файлу на раздел книги. Формат описан в `js/registry.js`:

```js
EGIU.unit(1, 'Present continuous (I am doing)', {
  tip: 'Краткое правило',
  g: ["Please be quiet. I [am trying|try|tried](try) to work."],   // первый вариант — правильный
  e: ["Look! It rains. => Look! It's raining."],                  // ошибка => исправление
  t: ["Ann is in the shower. (have a shower) => She's having a shower."],
  w: ['Задание для письма', 'Пример ответа'],
});
```

Из одного предложения в `g` автоматически строятся шесть заданий: выбор ответа, впиши форму, порядок слов, услышь и впиши, диктант и произношение.
Сокращения (`I'm` = `I am`, `don't` = `do not`, `'s` = `is`/`has`) при проверке считаются одинаковыми.

Упражнения составлены заново по темам книги, тексты из книги не копировались.


## Практика в контексте

Для всех 145 юнитов добавлен экран `#/u/<n>/context`: связанные ситуационные реплики, перевод, проверка смысла, собственный текст, вопросы для устного ответа и сохранённая самопроверка. Локальный разбор подсказывает несколько известных ошибок формы и написания; он не оценивает произвольный английский или произношение. Черновики и текст устного ответа входят в экспорт. Запись голоса временная, скачивается отдельно; уход со страницы освобождает микрофон.

Новые экзамены используют два конечных банка A/B отдельно от тренировки и чтения: по 13 разных примеров в смешанных форматах. Неиспользованный вариант выбирается первым; знакомый повтор обозначен. Старые попытки и результаты сохраняют свой источник. В заданиях на исправление и завершение фразы заданы смысл и лексическая рамка, чтобы не проверять свободный перевод строгим совпадением. После выпуска ответы банка нельзя менять без новой идентичности ссылок.

Экран `#/retention` добавляет закрытые темы в повторение: на следующий день, затем через 7 и 30 дней после успешной проверки. До трёх тем по шесть вопросов перемешиваются; нужны пять верных по каждой теме. Порядок и частичные ответы сохраняются. Ошибка переносит тему на завтра, ранняя практика не ускоряет интервал. `#/phrases` хранит фразы из контекста и собственные выражения; сначала попытка вспомнить, затем раскрытие и самооценка. Дополнительные дни и повторные XP за эти блоки не начисляются. После недельной проверки предлагается собственная речь по темам недели.

Свидетельства практики разделены: первый проход примеров, понимание контекста, письмо после самопроверки, устная самооценка и воспроизведение через время. Отсутствующий сигнал означает «ещё не проверено». Причину ошибки можно выбрать самостоятельно.

### Необязательный разбор через ProxyAPI

В настройках — личный ключ и модель: по умолчанию `openai/gpt-5.6-luna`, альтернатива `openai/gpt-5-mini`. По явно обозначенной платной кнопке отправляется только выбранный текст, задание и правило. Автоматических запросов, повторов и дорогого резервного варианта нет. По умолчанию лимит приложения — 5 ₽ в день по сохранённым тарифам; для окончательного ограничения расходов настрой бюджет отдельного ключа в ProxyAPI. Ответ проверяется по структуре и выводится безопасным текстом; ошибки, стиль, допустимые варианты и сомнения разделены. Повтор одинакового запроса открывает сохранённый разбор.

Рядом с неверным ответом, в итогах занятия, журнале ошибок и разборе сданного экзамена есть «Проверить с ИИ · платно». Проверка сравнивает ответ с условиями и ожидаемыми вариантами; список тренажёра не считается безусловно правильным. Для аудирования учитывается звучавшая фраза, для порядка слов — выданный набор. Вердикт, объяснение и перевод сохраняются по полному контексту задания, ответу и модели. «Зачесть мой ответ» появляется при вердикте о допустимости; оценка меняется только после нажатия. Отмена ложной ошибки сохраняет предшествующие повторения и не стирает более позднюю ошибку. В завершённом экзамене пересчитывается та же попытка; отдельный зачёт не создаёт новую попытку или второй закрытый день. Во время экзамена разбор недоступен.

Проверка принимает оба стандартных написания глагола organise/organize и его форм, сохраняя различия времён и слов. При загрузке точечно исправляются ранее отклонённые ответы экзаменов из новых банков, если они отличаются только этим написанием. Обновляются та же попытка, связанная статистика и ложная ошибка; свидетельства практики восстанавливаются только при проверяемой связи с первым экзаменом. Повторная загрузка не начисляет дополнительные ответы, дни или XP. Причина исправления отмечена в разборе. Пустое поле не показывает разбор предыдущего текста, при этом сохранённый результат остаётся в прогрессе.

После закрытого дня календарь и главная показывают следующий шаг: юнит на будний день или повторение на выходной, переход к собственной речи по закрытой теме и повторения, которые уже подошли по сроку. Этот блок не меняет текущую цель и не закрывает второй юнит.

Без отметки запоминания ключ живёт в текущей вкладке; с отметкой — на устройстве. Он хранится отдельно от прогресса и не экспортируется. Сброс и удаление ключа очищают оба хранилища. Общий ключ нельзя встраивать в публичный статический сайт; для приложения с общим аккаунтом нужен сервер.

### Материалы и проверки

В `content/learning-recipes.txt` — четыре шаблона конструкций на юнит. `scripts/build-learning-content.cjs` собирает из них смысловые варианты A/B, контекст, перевод и пояснения, сохраняя `js/data/` без изменений. Это контролируемые вариации, а не бесконечные новые ситуации. После изменения файлов обновляй отпечатки их URL в `index.html`; тест проверяет их соответствие.

```sh
node scripts/build-learning-content.cjs --check
node --test tests/*.test.cjs
```

API, бюджет и обработка ответа проверяются с имитацией сервиса. Реальную платную проверку можно проверить после ввода личного ключа; она не входит в автоматические тесты.
