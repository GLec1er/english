# Study Calendar Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement inline; no subagents are authorized. Track steps with checkboxes.

**Goal:** Добавить недельный ритм 5 дней по одному юниту и 2 дня повторения со статистикой.

**Architecture:** Небольшой модуль `js/study.js` вычисляет даты, сводки и статус дня из журнала. Существующий `app.js` записывает завершённые занятия и отображает календарь; данные книги остаются неизменными.

**Tech Stack:** Vanilla JavaScript, HTML/CSS; Node.js built-in test runner.

**Spec:** `docs/superpowers/specs/2026-10-11-study-calendar-design.md`

## Global Constraints

- Статические HTML/CSS/JS, GitHub Pages; без внешних библиотек и игровых наград.
- Местное время устройства; начало недели — понедельник.
- Старые результаты не изменяются и не превращаются в выдуманную историю.

## Review Focus

- Воскресенье и переход года должны попадать в свою неделю, понедельник — в следующую.
- Обычный микс и повтор ошибок не должны засчитывать план дня.
- Повторение прошлой недели не закрывает выходной текущей.
- Нулевой результат — выполненный подход, письмо не влияет на правильность ответов.
- Повреждённые записи нового журнала отбрасываются; пустая история остаётся пустой.
