# Workbook Redesign Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. Пользователь согласовал реализацию в текущем чате; субагенты не запрошены.

**Goal:** Превратить личный тренажёр после книги в спокойную, доступную рабочую тетрадь.

**Architecture:** Существующие HTML/CSS/JS, hash router и localStorage остаются. Структура экранов меняется в текущих функциях `app.js`, тема задаётся `data-theme` на корневом элементе, CSS использует общие переменные. Данные упражнений не редактируются.

**Tech Stack:** HTML, CSS, vanilla JavaScript, Node для проверки, GitHub Pages.

**Spec:** `docs/superpowers/specs/2026-10-11-workbook-design.md` (согласован пользователем 11 октября).

## Global Constraints

- 145 юнитов, состав заданий, хеш-маршруты и ключи `egiu:*` совместимы.
- Локальные шрифты; нет зависимостей, сервера, аналитики или платных услуг.
- Светлая бумага, графитовый текст, один красный акцент; единые SVG-иконки.
- Тёмная и системная темы выбираются явно в настройках.
- Внешняя публикация `main` не входит в текущую реализацию.

## Review Focus

- Первое посещение и нулевой прогресс: старт доступен, статистика правдива.
- Фильтр книги без отмеченных юнитов и поиск без результатов: ясное пустое состояние.
- Существующий прогресс с попыткой 0%: юнит считается начатым.
- Длинное название голоса и экран 320–390 px: нет горизонтального скролла.
- Клавиатура и динамическая проверка: подписи, фокус и объявления результата работают.
